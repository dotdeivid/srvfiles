# PinDialog.tsx

**Archivo:** `frontend/src/features/auth/PinDialog.tsx`
**Rol:** Modal que pide el PIN de 6 dígitos de un servidor.

---

Se usa al abrir un servidor protegido y desde el selector de servidores. Enfoca el campo al abrir, Escape cancela, muestra el host sin protocolo y el estado `submitting`.
